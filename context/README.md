# Backend Context

Эта папка хранит короткий контекст по Go-бэкенду сайта Ferrum et Gloria.

Файлы:

- `project.md` - назначение сервиса, стек, запуск, конфиги.
- `architecture.md` - слои приложения и где искать код.
- `api-and-data.md` - маршруты, сущности, миграции и важные данные.

Используй эти заметки перед правками в `internal`, `configs` и `migrations`.
